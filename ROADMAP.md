# Feuille de route

Cible : des **non-techniciens** qui veulent créer une page ou un petit site joli, sans écrire de code, sans peur de casser quoi que ce soit, et le mettre en ligne.

## Phase 1 — Utilisable sans aide

Objectif : quelqu'un construit sa page de A à Z sans qu'on lui explique.

- [x] Panneau Propriétés en langage simple (taille, alignement, couleurs du thème, espacement…), pas de CSS brut
- [x] Édition du texte directement sur la page (double-clic)
- [x] Annuler / Rétablir (Ctrl+Z / Ctrl+Y)
- [x] Sauvegarde automatique dans le navigateur
- [x] Supprimer, dupliquer, monter / descendre un bloc
- [x] Repère visuel indiquant où un bloc va être déposé, insertion à la bonne position
- [x] Ajouter une page
- [x] Raccourcis clavier (Suppr, Ctrl+D, Échap)
- [x] Ajout d'un bloc en un clic, recherche dans les composants
- [x] Panneau Calques (arbre des blocs) et fil d'Ariane dans les propriétés
- [x] 4 nouvelles sections prêtes : Menu, Texte + image, Galerie photos, Pied de page

## Phase 2 — Beau automatiquement

Objectif : impossible de faire moche.

- [ ] Modèles de pages complètes (portfolio, restaurant, événement, boutique)
- [x] Thèmes en un clic (8 ambiances : Minuit, Minimal, Élégant, Fun, Nature, Océan, Néon, Pro)
- [x] Palette générée à partir d'une couleur + vérification et correction automatique du contraste
- [x] Associations de polices (titres + texte) chargées depuis Google Fonts
- [ ] Aperçu mobile / tablette côte à côte sur le canvas, adaptation automatique

## Phase 3 — Utile pour de vrai

Objectif : la page est en ligne et fonctionne.

- [ ] Mode aperçu ▶ (sans les outils d'édition)
- [ ] Publication avec un lien partageable
- [ ] Liens entre pages (menu, boutons) → vrai mini-site
- [ ] Formulaire de contact qui envoie les messages par email
- [ ] Export HTML/CSS (option pour les curieux)

## Phase 4 — Effet « waouh »

- [ ] IA : « Fais-moi une page pour mon salon de coiffure » → page complète dans le thème choisi
- [ ] IA : réécrire un texte, générer une image
- [ ] Blocs réutilisables liés (on modifie le menu une fois, il change partout)
- [ ] Bibliothèque personnelle de blocs
